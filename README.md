Harry Potter API 🪄
Aplicación web desarrollada con Angular que consume la API REST de Potter DB para mostrar información del universo de Harry Potter.

Este proyecto forma parte del proyecto final de la asignatura Entornos de Desarrollo del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

✨ Funcionalidades
Secciones implementadas
Inicio: página principal con navegación entre las diferentes secciones de la aplicación.
Libros: sección dedicada a los libros de Harry Potter, con información como título, portada, dedicatoria, sinopsis y número de páginas y capítulos.
Personajes: sección para consultar información de los personajes, con filtros previstos por nombre, origen, tipo de sangre y casa de Hogwarts.
Películas: sección dedicada a las películas, con portadas, información y acceso a los tráileres.
Secciones pendientes
Hechizos: sección pendiente de desarrollo.
Pociones: sección pendiente de desarrollo.
🛠️ Stack tecnológico
Angular — desarrollo de la aplicación web.
TypeScript — lenguaje de programación.
HTML — estructura de la aplicación.
CSS — estilos y diseño.
PrimeNG — componentes de interfaz de usuario.
Potter DB API — obtención de información del universo de Harry Potter.
📱 Diseño responsive
La aplicación cuenta con un diseño responsive para adaptarse a diferentes tamaños de pantalla, facilitando su uso en distintos dispositivos.
